4. Update LEDs on the bus

WLED length and object addresses appear here once a controller is selected.

Insert

If you soldered LEDs into the chain: first increase the LED count in WLED, then choose the position here (e.g. after LED 5 if three new ones sit between old LED 5 and 6). All object addresses from the next LED are incremented. You cannot create more LEDs than WLED is configured for.

Remove

If you unsoldered LEDs from the chain: choose the first removed LED and the count (e.g. from LED 6, three pieces, if old LEDs 6–8 are gone). All later object addresses are decremented. A smaller LED count in WLED does not block this – the difference is shown above so you can update several places in sequence.

5. LED names

Names for single LEDs, RGB channels or ranges. In lists the name replaces “No. …” (e.g. LED 1 (street lamp)). Multiple color names appear separated by / (LED 12 (Halt / Proceed)). Inserting or removing on the bus moves the names with the LEDs. Numbers apply to the selected output (LED 1 is the first LED there).

Choose windows with the dropdowns and “Add window”. Rows use global LED indices.

Create sequence

A sequence switches the selected groups one after another. Between objects it waits a random pause between minimum and maximum (seconds). Switching off runs the order in reverse.

Create signal

Choose aspects with the dropdowns and “Add aspect”. Halt and proceed may share the same LED if red and green are split as RGB channels – then each color gets its own entry.

Create special

WLED effect on the selected LEDs. Contiguous LEDs form a segment. Switching only turns it on and off. Already used LEDs are marked in the lists. WLED effects always act on the whole pixel; the RGB channel applies when turning off.

Create vehicle

Static model with light channels. One pixel has three RGB channels (R, G, B) – that lets you switch three individual LEDs independently. Beacon: either LEDs in sequence or the RGB channels in sequence (one WS2811 = three LEDs, R→G→B). Indicators of several vehicles run at slightly different speeds on purpose.
